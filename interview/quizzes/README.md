# Self-assessment quizzes

Ten-question multiple-choice quizzes per curriculum module, with an answer key and one-line explanations. The purpose is triage: score yourself before a loop, and every miss names the chapter to restudy.

Two ways to run them: on paper (cover the key, answer, grade), or through the runnable quiz CLI - `python examples/interview_quiz_demo.py` - which loads [the CSV](../../datasets/interview_quiz.csv), asks, scores, and explains. The CSV carries the same questions for offline drilling.

## Scoring yourself

8-10: loop-ready on this module; revisit only the misses. 6-7: one restudy pass over the flagged chapters, then re-take. Below 6: the module is not yet yours - reread the flagged chapters and run the matching demo before spending interview credibility on it.
